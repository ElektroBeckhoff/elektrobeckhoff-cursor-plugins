# Formatter Test Fixtures

This directory contains the canonical test fixtures for the TwinCAT 3 Structured Text Formatter.

- **`raw/`**: Source test files before formatting.
- **`golden/`**: Canonical formatted ground-truth files (100% byte-matched).
- **`oneline/`**: Single-line stress test files.

See [VERIFICATION_RULES.md](./VERIFICATION_RULES.md) for full architecture and verification procedures.
