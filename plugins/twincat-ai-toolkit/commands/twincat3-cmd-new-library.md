# New Library

## Read first (in order)

Resolve this plugin root (folder that contains `skills/` and `rules/`). Then **Read**:

1. `skills/twincat3-new-library/SKILL.md`
2. `rules/twincat3-naming.mdc`
3. `rules/twincat3-versioning.mdc`
4. `rules/twincat3-xml.mdc`
5. `rules/twincat3-plcproj.mdc`
6. `rules/twincat3-core.mdc`

## Do

1. Follow the new-library skill completely.
2. Fresh GUIDs for every new object; preserve LF/encoding per `twincat3-xml`.
3. Register all new files in `.plcproj`.
